Idea: US Political Divisions Program
	My idea is to create using Java and JavaFX to make code that allows for the user to input a US political subdivision (State, county, city/township, census tract, etc.) and for the data for that subdivision to be displayed. It will display 2020 US Census data as well as some simple predictive calculations, like “projected population in 2050”. There will be a JavaFX interface that allows the user to select what data they want to see, and after the data is selected it will display at the bottom of the JavaFX interface. My program will be able to add multiple different subdivisions along with their unique features, like state mottos, year admitted to the Union, or county seat to name a few. 
	I am interested in this idea because I am a lover of geography and a GIS major. I’ve always liked maps and because of this I’ve become a good interpreter of the data they show. This idea deals with geographic political areas, but includes no maps. However; the data is what makes up maps. Recently I’ve become more and more into the data behind the maps as that is why maps look the way they do. My project shows geographic information as well as demographics and predictions. It isn’t very sophisticated, but I am proud of what I’ve made with my short experience in coding. 
	I initially based this project off of the MVP code we worked on in class. I do not have a perfect understanding of MVP yet, but I believe I got it working for my project which is very exciting. I think this code has flexible design patterns for the most part. It isn’t going to be hard to make another subdivision like census tracts, though it will require editing in multiple classes. Adding states or counties to their respective hashmap will be extremely simple. JavaFX also confuses me sometimes, but I got it working, though there definitely is room for improvement with it. I genuinely would like to continue editing and updating this code over the summer.
